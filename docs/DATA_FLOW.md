```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         CV PARSING PIPELINE                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ENTRADA:                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  cv_file.pdf (o .docx)                                             │   │
│  │  Tamaño: 245 KB                                                    │   │
│  │  Páginas: 2                                                        │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                      │                                      │
│                                      ▼                                      │
│  PASO 1: EXTRACCIÓN DE TEXTO                                                │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  if format == "PDF":                                               │   │
│  │      text = pdfplumber.extract_text(file)                          │   │
│  │  elif format == "DOCX":                                            │   │
│  │      text = python_docx.extract_text(file)                         │   │
│  │                                                                     │   │
│  │  Salida: "Juan Pérez\njuan@email.com\n..." (3,245 caracteres)     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                      │                                      │
│                                      ▼                                      │
│  PASO 2: LIMPIEZA                                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  text = re.sub(r'\s+', ' ', text)      # Normalizar espacios      │   │
│  │  text = re.sub(r'[^\w\s@.]', '', text) # Remover caracteres raros │   │
│  │  text = text.strip()                   # Quitar whitespace        │   │
│  │                                                                     │   │
│  │  Salida: "Juan Pérez juan@email.com ..." (limpio)                 │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                      │                                      │
│                                      ▼                                      │

│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  doc = nlp(text)                                                   │   │
│  │                                                                     │   │
│  │  for ent in doc.ents:                                              │   │
│  │      if ent.label_ == "PERSON":  → name = "Juan Pérez"            │   │
│  │      if ent.label_ == "EMAIL":   → email = "juan@email.com"       │   │
│  │      if ent.label_ == "ORG":     → companies = ["Tech Corp"]      │   │
│  │      if ent.label_ == "DATE":    → dates = ["2021-2024"]          │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                      │                                      │
│                                      ▼                                      │

│  │  ]                                                                 │   │
│  │                                                                     │   │

## 3. Flujo de Datos: Matching

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         MATCHING PIPELINE                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ENTRADAS:                                                                  │
│  ┌───────────────────────────┐  ┌───────────────────────────┐             │
│  │ ParsedCV                  │  │ Job                        │             │
│  │ {                         │  │ {                          │             │
│  │   skills: ["Python",      │  │   skills: ["Python",       │             │
│  │            "SQL",         │  │            "Django",       │             │
│  │            "AWS"]         │  │            "PostgreSQL"]   │             │
│  │   experience: 5 years     │  │   required_exp: 3 years    │             │
│  │   education: "Bachelor"   │  │   education: "Bachelor"    │             │
│  │ }                         │  │ }                          │             │
│  └───────────────────────────┘  └───────────────────────────┘             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                         COMPONENTE 1: SKILLS MATCH (40%)                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  cv_skills = ["Python", "SQL", "AWS"]                                      │
│  job_skills = ["Python", "Django", "PostgreSQL"]                           │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  matched = []                                                      │   │
│  │  missing = []                                                      │   │
│  │                                                                     │   │
│  │  for job_skill in job_skills:                                      │   │
│  │      if job_skill in cv_skills:                                    │   │
│  │          matched.append(job_skill)     # "Python"                  │   │
│  │      else:                                                         │   │
│  │          missing.append(job_skill)     # "Django", "PostgreSQL"   │   │
│  │                                                                     │   │
│  │  skill_score = len(matched) / len(job_skills)                      │   │
│  │  skill_score = 1 / 3 = 0.33                                       │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Fuzzy Matching (opcional):                                                 │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  # "SQL" vs "PostgreSQL"                                           │   │
│  │  ratio = fuzz.ratio("sql", "postgresql")  # → 45 (no match)      │   │
│  │                                                                     │   │
│  │  # "AWS" vs "Amazon Web Services"                                 │   │
│  │  ratio = fuzz.ratio("aws", "amazon web services")  # → 30        │   │
│  │                                                                     │   │
│  │  # Usar token_sort_ratio para variaciones                         │   │
│  │  ratio = fuzz.token_sort_ratio("Amazon Web Services", "AWS")      │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  RESULTADO: skill_score = 0.33 (ajustable con fuzzy)                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                         COMPONENTE 2: EXPERIENCE MATCH (25%)                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  cv_experience = 5 años                                                     │
│  job_required = 3 años                                                      │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  if cv_experience >= job_required:                                 │   │
│  │      exp_score = 1.0                                               │   │
│  │  else:                                                             │   │
│  │      exp_score = cv_experience / job_required                      │   │
│  │                                                                     │   │
│  │  # 5 >= 3 → exp_score = 1.0                                       │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  RESULTADO: exp_score = 1.0                                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                         COMPONENTE 3: EDUCATION MATCH (15%)                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  cv_education = "Bachelor"                                                  │
│  job_education = "Bachelor"                                                 │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  # Niveles educativos                                              │   │
│  │  edu_levels = {                                                    │   │
│  │      "phd": 5, "master": 4, "mba": 4,                            │   │
│  │      "bachelor": 3, "associate": 2, "diploma": 1                  │   │
│  │  }                                                                 │   │
│  │                                                                     │   │
│  │  cv_level = edu_levels["bachelor"]  # → 3                         │   │
│  │  job_level = edu_levels["bachelor"]  # → 3                        │   │
│  │                                                                     │   │
│  │  if cv_level >= job_level:                                         │   │
│  │      edu_score = 1.0                                               │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  RESULTADO: edu_score = 1.0                                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                         COMPONENTE 4: TF-IDF SEMANTIC (20%)                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  cv_text = "Desarrollador Python con experiencia en cloud computing..."    │
│  job_text = "Buscamos senior Python developer, conocimientos AWS..."       │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  # TF-IDF Vectorization                                           │   │
│  │  vectorizer = TfidfVectorizer(max_features=1000)                   │   │
│  │                                                                     │   │
│  │  # Fit y transform                                                │   │
│  │  tfidf_matrix = vectorizer.fit_transform([cv_text, job_text])     │   │
│  │                                                                     │   │
│  │  # Cosine Similarity                                              │   │
│  │  cosine_sim = cosine_similarity(                                    │   │
│  │      tfidf_matrix[0:1],                                            │   │
│  │      tfidf_matrix[1:2]                                             │   │
│  │  )[0][0]                                                           │   │
│  │                                                                     │   │
│  │  # cosine_sim = 0.78                                              │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  RESULTADO: semantic_score = 0.78                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                         COMPONENTE 5: SCORE FINAL                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  # Pesos                                                           │   │
│  │  WEIGHTS = {                                                       │   │
│  │      "skills": 0.40,                                               │   │
│  │      "experience": 0.25,                                           │   │
│  │      "education": 0.15,                                            │   │
│  │      "semantic": 0.20                                              │   │
│  │  }                                                                 │   │
│  │                                                                     │   │
│  │  # Cálculo                                                        │   │
│  │  total_score = (skill_score × 0.40) +                             │   │
│  │                (exp_score × 0.25) +                                │   │
│  │                (edu_score × 0.15) +                                │   │
│  │                (semantic_score × 0.20)                             │   │
│  │                                                                     │   │
│  │  total_score = (0.33 × 0.40) + (1.0 × 0.25) +                    │   │
│  │                (1.0 × 0.15) + (0.78 × 0.20)                       │   │
│  │                                                                     │   │
│  │  total_score = 0.132 + 0.25 + 0.15 + 0.156 = 0.688                │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  # Clasificación                                                  │   │
│  │  if total_score >= 0.80:                                           │   │
│  │      classification = "BUENO"       # 80-100%                     │   │
│  │  elif total_score >= 0.50:                                         │   │
│  │      classification = "REGULAR"     # 50-79%                      │   │
│  │  else:                                                             │   │
│  │      classification = "NO_MATCH"    # <50%                        │   │
│  │                                                                     │   │
│  │  # 0.688 → "REGULAR"                                              │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  SALIDA: MatchResult                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  {                                                                  │   │
